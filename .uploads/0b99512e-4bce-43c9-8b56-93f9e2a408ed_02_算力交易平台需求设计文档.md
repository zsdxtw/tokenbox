## 一、平台定位

**一句话定位**：面向"设备—算力—金融"全生命周期的算力资产交易与金融化基础设施平台。

**三个关键词**：

1. **交易**：设备（一手/二手）与算力（TOKEN）的双市场撮合与价格发现；
2. **金融**：让 GPU/智算设备从"主体信用附属担保物"升级为"可独立定价、可抵押、可快速处置的资产信用"；
3. **处置**：为银行/金租等债权方提供"违约预警 → 押品接管 → 快速变现 → 资金监管"的处置闭环，处置资产直接回流平台二手与租赁市场。

**设计原则**：

| 原则         | 说明                                                 |
| ---------- | -------------------------------------------------- |
| 闭环优先       | 设备交易、算力交易、金融服务不是三个孤岛；残值曲线由交易数据生成，反哺融资定价，处置出口接回交易市场 |
| 价格即服务      | 成交价指数与残值曲线是平台第一性服务，是银行、保险、买家的信任锚点                  |
| 双市场分层      | 专业算力（训练级/长约/闭口）与闲散算力（现货/尽力而为）规则完全分离                |
| 双 TOKEN 形态 | 同时支持设备租赁型算力（卡时/机时）与大模型 TOKEN 型算力（API 调用量）          |
| 合规内建       | 国产化率校验、数据清除认证、跨境通道隔离、押品登记对接，作为功能而非事后补丁             |

**平台总架构**：

```
┌────────────────────────────────────────────────────────┐
│                    算力交易平台（门户）                   │
├──────────────┬──────────────┬───────────────────────────┤
│  M1 设备交易  │  M2 算力交易  │  M5 解决方案中心            │
│  一手/二手/   │  专业算力/    │  智算建设/国产化/           │
│  供需/检测/   │  闲散算力/    │  托管运维/绿色算力          │
│  交付        │  租赁型/TOKEN型│                            │
├──────────────┴──────────────┴───────────────────────────┤
│              M3 金融服务中心（融资/租赁/保险/RWA）         │
│              M4 金融资产处置中心（银行押品专区）★          │
├─────────────────────────────────────────────────────────┤
│  M0 平台公共服务：估值指数中心 / 设备健康档案 / 检测认证 /   │
│  调度计量计费 / 资金结算与监管 / 信任与合规 / 用户与机构      │
└─────────────────────────────────────────────────────────┘
```

## 三、模块需求

### M1 设备交易中心

#### M1.1 业务模式

- **一手交易**：OEM/总代/代理入驻挂牌，平台提供集采拼单、预售锁价；内建国产化合规校验（按买方主体类型自动校验国产化率与采购限制）。
- **二手交易**：三种挂单方式——单卡/整件挂牌、同质批组挂牌（批组溢价规则）、大宗暗盘撮合（OTC，买家发起询价、平台经纪人撮合）。
- **供需发布**：需求大厅（买方发布设备求购：型号/数量/时限/预算），货源大厅（卖方发布货源意向：可先发布后补充检测报告）。
- **寄售与回购**：卖家可将设备委托平台寄售（定价建议由估值引擎给出）；平台生态买家池提供快速回购报价（24 小时内出价）。

#### M1.2 功能需求

| 编号    | 功能          | 说明                                                |
| ----- | ----------- | ------------------------------------------------- |
| M1-01 | 一手商城        | 品牌馆、预售/集采、国产化合规标签                                 |
| M1-02 | 二手市场        | 挂牌列表、SKU 级检索（型号/显存/成色/来源）、批组视图                    |
| M1-03 | 供需大厅        | 求购/供货双向发布、自动匹配推送、撮合成功率看板                          |
| M1-04 | 竞价拍卖        | 限时竞价（二手）、反向竞价（求购）、荷兰式降价（滞销库）                      |
| M1-05 | 大宗撮合        | OTC 询报价单（RFQ→报价→还价→锁单）、经纪人工作台                     |
| M1-06 | 交易订单        | 合同电子签、保证金、履约状态机（锁定→付款→检测→过户→交付）                   |
| M1-07 | 检测认证（对接 M0） | 下单即触发第三方检测：burn-in 测试、ECC 错误计数、热历史、显存压测；出具设备体检报告  |
| M1-08 | 物流交付        | 专线物流（防震/防静电）、机房上架、安装调试服务下单与验收                     |
| M1-09 | 数据清除认证      | 针对含存储部件设备：擦除/消磁/物理销毁三档，全程录像留档，出具认证证书（金融/政企卖方硬性要求） |
| M1-10 | 价格看板        | SKU 实时挂牌价 vs 平台成交价中位数对比（对标国际 CCIR 双轨模式）           |

#### M1.3 关键流程（二手交易）

```
卖方挂牌 → 估值引擎预评 → 买家下单（冻结保证金）
→ 第三方检测出报告 → 报告不符可退单 / 符合则付款至监管账户
→ 过户与数据清除认证 → 物流交付/机房上架 → 买家验收
→ 监管账户放款（T+1）→ 双向互评、生成成交价数据
```

### M2 算力与 TOKEN 交易中心

#### M2.1 业务模式：四个子市场

**（A）专业算力市场（训练级/高性能集群）**

- 标的：千卡级集群、超节点整机（如 8 卡 H100/H200/昇腾 910B3+ 整机）、NFV/裸金属。
- 交易方式：**长约闭口**（1–5 年、保底量、锁价，对标市场"两年闭口+一年开口"混合合同）与**大宗撮合**（百卡以上需求走 RFQ 经纪撮合）。
- SLA：白金级（99.9% 可用性、故障赔付、专属机房、带宽/IB 网络保障）。

**（B）闲散算力市场（现货/尽力而为）**

- 标的：闲散 GPU（企业闲置服务器、个人工作站、消费级 4090 等）。
- 机制：供给方接入平台 Agent（自动上报 GPU/显存/利用率遥测并接单），按卡时/机时现货挂价，平台调度就近/低价匹配；对标 io.net 模式，定价可为云厂商的 3–7 折。
- SLA：尽力而为级，任务断点续跑、多节点冗余校验。

**（C）设备租赁型算力（融资租赁联动）**

- 标的：整机/整柜/整机房包月租赁，卡时零售。
- 联动：租赁合同可一键转"融资租赁"（对接 M3 金租直租），租期届满留购（对标"100 元留购"条款）；供给方可将租赁应收账款质押融资。

**（D）大模型 TOKEN 型算力（API 交易）**

- 标的：模型 API 的 token 额度（输入/输出/缓存读取分开计价）、推理实例独占。
- 机制：
  - **token 预付费卡/额度包**：平台聚合采购主流模型与自部署模型推理资源，零售 token 包（参考市场：输出约 12.7 元/M、缓存读取 0.03–1.5 元/M、Flash 模型 0.4 元/M）；
  - **token 预售与远期**：推理服务商可预售未来 token 产能（折扣价锁定），平台提供交割核销；
  - **推理算力竞价**：同任务规格（如 70B FP8、1024 ctx）由多家推理供给方报价抢单，按"每百万 token 价格"比价成交。
- 计量：统一计量网关（调用日志、tokens 计数、延迟/成功率），支持缓存命中差异化计费。

#### M2.2 功能需求

| 编号    | 功能            | 说明                                                               |
| ----- | ------------- | ---------------------------------------------------------------- |
| M2-01 | 专业算力商城        | 集群/整机/裸金属列表、规格书、闭口长约下单                                           |
| M2-02 | 闲散算力市场        | 现货挂价、供给 Agent 接入、任务调度（就近/低价/冗余）                                  |

### M3 金融服务中心

#### M3.1 设计目标

把"设备信用"从主体信用中独立出来。平台提供四层支撑：**估值（M0 指数+残值曲线）→ 押品登记（人行动产融资统一登记系统对接）→ 贷后监控（算力遥测）→ 处置出口（M4）**。

#### M3.2 业务模式

| 服务                | 模式                    | 说明                                                   |
| ----------------- | --------------------- | ---------------------------------------------------- |
| 设备抵押融资            | 平台协助评估+银行/金租放款        | 放款率建议 50–70%（参考国际 GPU-backed lending）；估值以平台成交价中位数为基准 |
| 融资租赁/售后回租         | 对接金租直租与回租             | 期满留购条款、经营业绩触发提前清偿条款模板                                |
| 应收账款质押/保理         | 租赁/算力服务应收融资           | 仅覆盖已签合同应收，禁止以预期现货需求支持长期债务                            |
| 交易分期              | 买方分期购设备               | 首付+平台担保+设备抵押登记，违约设备进 M4 处置                           |
| 算力收益权 ABS/RWA（预留） | SPV 打包算力收益权           | 一期对接 ABS；二期预留香港 RWA 通道（海外算力资产、合规沙箱内试点）               |
| 保险                | 设备财产险/断租损失险/处置差价险     | 处置差价险：赔付"处置成交价低于评估值"的差额，提升银行放款意愿                     |
| 回购承诺增信            | 平台/生态方对指定 SKU 出具回购价承诺 | 对标英伟达残值保证模式，以中国"平台+生态买家池"方式实现                        |

### M4 金融资产处置中心（银行押品专区）★

> 需求来源：智算中心大量设备抵押给银行融资，贷款违约后银行需要快速处置、回款。该板块独立运营，但处置出口与 M1/M2 深度打通——**违约设备不必折价甩卖，而是回流平台交易市场获得市场化价格**。

#### M4.1 业务模式

**（A）贷前押品准入（与 M3 联动）**

- 押品建档：型号/序列号/SKU/批组/机房位置/访问凭证（托管）→ 统一押品 ID；
- 入库评估：估值引擎出具"评估价 = 平台成交价中位数 × 状态系数 × 流动性系数"，附残值曲线与处置预估周期；
- 押品登记与保险建议一键完成。

**（B）贷中监控与违约预警**

- 接入算力遥测与租金回款：利用率连续 N 日 < 阈值、租金逾期、上架率跌破线、市价跌幅超 X% 自动预警；
- 押品价值月度/季度重估（对标国际"按季下调押品估值表"），LTV 超限自动通知补充担保。

**（C）违约处置：三条快速通道**

| 通道        | 时效      | 适用          | 说明                                    |
| --------- | ------- | ----------- | ------------------------------------- |
| T1 快速回购   | ≤7 天    | 流动性好的热门 SKU | 生态买家池/平台自营预出价，先到先得锁定，评估价 90–95% 成交    |
| T2 公开竞价   | 7–15 天  | 中等流动性、数量适中  | 押品专区挂牌拍卖（保留价=评估价 85%），全流程司法/合同留痕，支持多轮 |
| T3 整包大宗处置 | 15–30 天 | 大批量/跨机房/含配套 | 平台经纪撮合，整机房打包出售（含机房租约、电力、运维合同整体承接）     |

**（D）处置保障机制**

- **资金监管**：处置成交款进入共管监管账户，按贷款合同分配（本金→罚息→费用→余额返还借款人），全程可追溯；
- **绿色通道**：与律所/公证/机房托管方建立预设协议（step-in rights 介入权、设备远程锁定技术手段），保证"接管无纠纷、数据可清除、过户无障碍"；
- **处置差价险理赔**（对接 M3）：差额部分由保险赔付；
- **合规留痕**：全流程时间戳存证，出具《处置报告》供银行内部审计与监管报送。

**（E）反向赋能**

- 处置产生的成交数据回流价格指数；银行在放贷端因处置通道存在而提高放款意愿与放款率——**处置能力就是授信能力**。

#### M4.2 功能需求

| 编号    | 功能     | 说明                                           |
| ----- | ------ | -------------------------------------------- |
| M4-01 | 押品库    | 押品建档、序列号/机房位置/访问凭证管理、登记状态、保险状态               |
| M4-02 | 估值与重估  | 入库评估、月度/季度自动重估、LTV 看板、补充担保通知                 |
| M4-03 | 违约预警中心 | 多源预警（遥测/回款/市价）、分级预警（关注/可疑/违约）、处置建议自动生成       |
| M4-04 | 处置工作台  | 通道选择建议（T1/T2/T3）、处置流程引擎（接管→检测→数据清除→挂牌→成交→过户） |
| M4-05 | 押品拍卖专区 | 面向买家的独立入口"银行押品专场"，与二手市场互通展示                  |
| M4-06 | 资金监管   | 共管账户、清分规则配置、分配方案与凭证                          |
| M4-07 | 处置报告   | 全流程留痕、时间戳存证、一键生成 PDF 供审计/监管                  |
| M4-08 | 银行端门户  | 机构独立视图：押品总览、预警收件箱、处置进度、回收率统计                 |

#### M4.3 关键流程（违约快速处置）

```
违约确认 → 处置建议（估值引擎按 SKU 流动性推荐 T1/T2/T3）
→ 债权方确认启动 → 托管方执行接管（远程锁定/现场封存，介入权预设协议）
→ 第三方检测 + 数据清除认证 → 挂牌（回购价/拍卖保留价）
→ 成交 → 买家付款至监管账户 → 过户交付（复用 M1 流程）
→ 资金清分（本金→罚息→费用→余额）→ 出具处置报告 → 数据回流指数
```
