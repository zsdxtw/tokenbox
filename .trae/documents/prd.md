## 1. 产品概述

AI导航站是一个聚合全球AI平台入口的导航网站，帮助用户快速发现、比较和进入各类AI工具平台。通过清晰的分类体系和直观的界面设计，解决用户在海量AI工具中"找不到、选不对"的痛点，成为用户进入AI世界的首选入口。

- 目标用户：AI从业者、开发者、设计师、内容创作者、学生及所有对AI工具感兴趣的用户
- 核心价值：一站式AI工具发现与导航，降低用户寻找合适AI工具的门槛

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通访客 | 无需注册 | 浏览全部分类、搜索工具、点击跳转 |
| 注册用户 | 邮箱注册 | 收藏工具、自定义导航、提交工具 |

### 2.2 功能模块

1. **首页**：搜索栏、热门推荐、分类导航、最新收录
2. **分类浏览页**：按领域分类展示AI工具，支持筛选排序

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | 顶部导航栏 | Logo、搜索框、分类快捷入口、主题切换 |
| 首页 | Hero区域 | 大标题、搜索框、热门标签云 |
| 首页 | 热门AI推荐 | 展示当前最热门的AI工具卡片（名称、图标、简介、直达链接） |
| 首页 | 分类导航区 | 按领域分类展示，每个分类含图标+名称+工具数量，点击展开该分类 |
| 首页 | 最新收录 | 展示最新收录的AI工具 |
| 首页 | 页脚 | 版权信息、友情链接、联系方式 |
| 分类浏览页 | 侧边分类栏 | 左侧固定分类目录，支持展开子分类 |
| 分类浏览页 | 工具卡片列表 | 右侧展示当前分类下的工具卡片，支持网格/列表切换 |
| 分类浏览页 | 筛选排序 | 按免费/付费、热度、最新等维度筛选排序 |

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深色科技风，主色 #0A0F1E（深蓝黑），强调色 #00D4FF（电光蓝），辅助色 #7C3AED（紫色）
- **按钮风格**：圆角胶囊按钮，hover时发光效果
- **字体**：标题使用 "Orbitron" 科技感字体，正文使用 "Noto Sans SC" 中文字体
- **布局风格**：左侧固定分类导航 + 右侧内容区，卡片式展示
- **图标风格**：线性图标搭配渐变色，科技感强
- **背景**：深色渐变 + 微粒网格纹理，营造赛博朋克科技氛围

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | Hero区域 | 深色渐变背景，大标题发光效果，搜索框带动态边框，热门标签浮动动画 |
| 首页 | 热门AI推荐 | 横向滚动卡片，卡片带玻璃拟态效果，hover时卡片上浮+发光 |
| 首页 | 分类导航区 | 网格布局分类卡片，每个分类带渐变图标，hover时图标旋转 |
| 首页 | 最新收录 | 竖向列表，带"NEW"标签，入场动画 |
| 分类浏览页 | 侧边分类栏 | 固定定位，当前分类高亮，子分类缩进展示 |
| 分类浏览页 | 工具卡片 | 网格卡片，含logo/名称/简介/标签/直达按钮，hover发光 |

### 4.3 响应式设计

- 桌面优先设计，支持1920px/1440px/1024px断点
- 移动端适配：侧边栏变为顶部下拉菜单，卡片从多列变为单列
- 触屏优化：增大点击区域，卡片支持滑动浏览
